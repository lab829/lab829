CodeRunner – The simplest way to run JavaScript on your browser

CodeRunner is a lightweight JavaScript sandbox built for learners and tinkerers. No setup. No Node. Just type, run, and see your code in action.

  • Run instantly – Write JavaScript in the editor and hit Run to see results in the Output panel.
  • Organize your work – Save, import, export, and manage files with the built-in Files drawer.
  • Copy anywhere – Move your code to another IDE or project with one click.
  • Distraction-free coding – Expand the editor to full screen and focus purely on your code.
  • Always accessible – Works right in your browser, offline-ready and zero install.
  • PWA ready – Install CodeRunner on your device for offline access.
Currently in Beta – simple, fast, and growing. We're building new features and a clear roadmap to make Code Runner the easiest way to practice JavaScript on the go.

Aloe Theme – A minimal, dark green theme for VS Code

Aloe is a dark VS Code theme with a calm green base, tuned for WCAG-friendly contrast and smooth day-long coding. Brackets, JSX tokens, and UI chrome have been hand-curated to avoid harsh neon tones while still keeping structure easy to scan.

  • Balanced green and teal accents that stay readable on low-brightness displays
  • Dedicated token colors for JSX spreads, template expressions, and variables
  • Soft bracket pair coloring without the default pure yellow/blue clash
  • Accessible diff and peek highlights that distinguish insertions, deletions, and borders without eye strain
  • Polished workbench styling (tabs, breadcrumbs, minimap, sidebar) for a seamless UI
Available Now! Give it a try, rate it, and let us know what you think! Open an issue on GitHub if you have any feedback.
